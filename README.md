**Neon Palms: The Marlin Vault** — a complete heist game. Slip across a neon casino vault floor in the dead of night, read the guards' sweeping vision cones and the CCTV cameras, lift the Marlin Diamond and the cash, and reach the getaway boat before the alarm meter hits 100%.

Three routes per room (main floor, service corridor, vents), tools at a cost (EMP, smoke, lockpick), patrols you have to read before you move. Keyboard + mouse, offline, static files.

## Run it

```sh
npx serve game
# open http://localhost:3000 in desktop Chrome
```

Or serve `game/` with any static server and open `index.html`.

## Controls

- **WASD / arrows** — move (Shift = sneak, slower and harder to spot)
- **Mouse click** — use the selected tool at that spot / grab loot
- **1 / 2 / 3** — select EMP / Smoke / Lockpick
- **Space** — dash · **P** — pause · **M** — sound

## Win / Lose

- **Win:** grab the Marlin Diamond, then reach the getaway boat dock.
- **Lose:** alarm hits 100% three times, or all three lives are lost.
